# VCHP(VoidCat HomePage)
基于 Vue 打造的现代化的个人主页。  
[在线预览](https://meali.top)  
## 为什么我要做这个
- 现有的方案过于臃肿且复杂。
- 我想打造以个人主页为主的，博客为辅的网站，现有的基本上都是博客为主，个人主页的内容很少。
- 现有的大多数是2010年的风格，不符合我的审美。
## 这个的优点是什么
- 极致轻量，简洁，模块化。
- 高性能，Lighthouse 分数高达99分。
## 常用命令
`pnpm dev`运行开发服务器  
`pnpm build`构建  
`pnpm new-post <id>`创建新文章
